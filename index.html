S.T.A.R.S. - Lunar Sleep Shift Scheduling Tool

Problem Statement

NASA needs an autonomous sleep scheduler that’s able to schedule healthy sleep patterns for Astronauts in case of communication delays and other communication related problems.

Research

  1. Physical Fatigue
    • Insufficient sleep doesn’t allow for micro-damages to be repaired
    • Your cells aren’t able to produce enough energy
  2. Mental Fatigue
    • Your brain doesn’t flush out toxic byproducts
    • Delayed reaction time and critical thinking, leading to tasks being more dangerous
    • 7-9 hours of sleep is recommended, but might not work for astronauts

Software

  1. Advice Software
    • Takes strenuousness scores and calculates fatigue score (Out of 100)
    • Takes the amount of sleep a user would get and their longest consecutive sleep and changes fatigue score
    • Gives advice based on fatigue score
  2. Storage Software
    • The data of each persons schedule with strenuousness and mental strain score is stored in a seperate binary file marked “.lsg”. This file stores each day by the date and each activity by start time and end time. The file currently lacks mutability of already added data and specific querying of data.
